Contribute Your Own Tools

ZTools is built for the community. You can write tools in any language—Go, Python, TypeScript, Rust, or Bash—and register them in minutes.

01

Author the Tool

Build your executable or script to accept JSON over stdin and write formatted JSON to stdout.

tools/my_tool/main.go
02

Declare Manifest

Create <tool_name>.json defining parameter schemas, command invocation, and execution timeout.

tools/my_tool/my_tool.json
03

Submit via Pull Request

Add an entry to registry.json and open a GitHub PR. Our automated CI verifies schemas and publishes your tool!

registry.json
